# 小牛截图解题器

纯前端的小牛逻辑题截图识别与求解工具。上传游戏截图后，浏览器会自动识别棋盘颜色、计算落点并在图片上标注答案。

在线使用：[https://aboutthepast.github.io/cow-screenshot-solver/](https://aboutthepast.github.io/cow-screenshot-solver/)

## 本地预览

无需安装 Python、Node.js 或任何依赖。直接打开 `index.html`，或在项目根目录运行任意静态文件服务器，例如：

```bash
python3 -m http.server 8000
```

再访问 <http://127.0.0.1:8000>。

## 识别前提

- 适用于截图中这种由等大的彩色方块组成、每种颜色刚好放一头小牛的关卡。
- 请上传原始、完整、未裁切的游戏截图；棋盘不要被弹窗、手指或悬浮控件遮住。
- 颜色识别基于截图本身，因此不要开启会改变整体色彩的色盲模式、护眼滤镜或系统调色。
- 已经画出的叉号或小牛图案会尽量被主色识别忽略；最佳效果仍是上传刚进入关卡时的干净棋盘截图。

图片不会保存到磁盘，也不会上传到网络；识别、求解和标注均在当前浏览器内完成。GitHub Pages 只负责托管网页文件，不会接收截图。

## GitHub Pages 部署

仓库使用 `main` 分支根目录作为 Pages 发布源。推送到 `main` 后，GitHub 会自动发布最新静态页面；无需构建步骤或服务器。
