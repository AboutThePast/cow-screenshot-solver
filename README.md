# 抖音《佛系消消消》小牛截图解题器

一个面向抖音《佛系消消消》小牛关卡的纯前端求解工具。上传游戏截图后，网页会在浏览器本地识别棋盘颜色，计算每头小牛的落点，并生成带编号的标注图。

**在线体验：** [aboutthepast.github.io/cow-screenshot-solver](https://aboutthepast.github.io/cow-screenshot-solver/)

## 功能

- 支持点击上传、拖放图片和直接粘贴截图。
- 支持 PNG、JPG、WebP 格式，单张图片最大 15 MB。
- 自动定位彩色方格棋盘，并识别每个格子的主色。
- 输出每头小牛应放置的行、列坐标，并在截图上标出顺序。
- 如果存在多个可行解，会明确提示并展示其中一个解。
- 无后端、无账号、无图片上传：识别、求解和标注都在当前浏览器完成。

## 使用方法

1. 打开[在线页面](https://aboutthepast.github.io/cow-screenshot-solver/)。
2. 上传完整的游戏关卡截图，或把截图拖进页面，也可以复制截图后直接按 <kbd>⌘</kbd> + <kbd>V</kbd>。
3. 等待页面识别棋盘并求解。
4. 根据右侧列出的“第几行、第几列”点击游戏中的格子；左侧标注图可用于核对位置。

坐标从棋盘左上角开始计数，行从上到下递增，列从左到右递增。标注图中的红色数字仅是输出顺序，不影响实际点击顺序。

## 适用范围

本工具面向抖音《佛系消消消》中由等大彩色方块组成的小牛关卡，按照以下规则求解：

- 每一行恰好放置一头小牛；
- 每一列恰好放置一头小牛；
- 每种颜色恰好放置一头小牛；
- 相邻两行中的小牛不能位于相邻或相同列，从而避免斜向相邻。

为取得最佳识别效果，请使用刚进入关卡时的原始全屏截图，并确保：

- 棋盘完整出现在截图中，未被手指、弹窗或悬浮控件遮挡；
- 未开启色盲模式、护眼滤镜或会改变全局颜色的系统调色；
- 画面尽量清晰，避免过度压缩、裁剪或模糊；
- 即使已有叉号或小牛图案，程序会尽量忽略覆盖图标，但干净棋盘的成功率更高。

## 隐私说明

截图不会被上传到服务器，也不会被保存到磁盘。页面使用浏览器 Canvas 读取像素、完成计算并在内存中绘制标注图；GitHub Pages 仅托管 HTML、CSS 和 JavaScript 静态文件，无法接收你的图片数据。

## 工作原理

1. 在截图的棋盘区域中检测高饱和度的彩色像素，定位连续的行、列方格。
2. 从每个格子的中心区域采样，过滤图标、文字和白色覆盖物，得到该格子的主色。
3. 按颜色距离聚类，构建颜色编号棋盘。
4. 通过回溯搜索同时满足行、列、颜色和相邻限制的摆放方案。
5. 将第一个可行解绘制为红色编号圆点，并显示对应坐标。

为避免超大截图占用过多内存，浏览器会在识别前将图片限制在最长边 2500 像素、最多 500 万像素的范围内；这不会影响正常手机截图的识别。

## 常见问题

### 提示“未识别出连续棋盘行”

通常是棋盘被裁掉、遮挡，或截图中没有包含完整关卡。请上传未裁切的原始截图。

### 提示“棋盘行列数不一致”

请检查棋盘是否被弹窗、手势条或悬浮按钮覆盖，并保证画面没有严重拉伸或变形。

### 提示“得到的颜色种类不符合棋盘大小”

请关闭色盲模式、护眼滤镜和系统调色后重试；过度压缩的图片也可能造成同色被误判为不同颜色。

### 页面不支持某张图片

请使用 PNG、JPG 或 WebP 格式，且图片大小不超过 15 MB。推荐直接粘贴或上传手机保存的原始截图。

## 本地预览

项目没有构建步骤，也不依赖 Python、Node.js 或第三方包。可直接打开 `index.html`，也可以在项目根目录启动任意静态文件服务器：

```bash
python3 -m http.server 8000
```

然后打开 <http://127.0.0.1:8000>。
